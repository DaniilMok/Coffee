# CoffeeMat Project

Приложение для Windows Forms, моделирующее работу кофейни.

Проект был создан в 2024 году как первый самостоятельный проект в процессе изучения C# и разработки под .NET.

## Функциональность

- Работа со списком напитков
- Расчёт стоимости заказа
- Графический интерфейс пользователя (Windows Forms)
- Использование базовых принципов ООП

## Обновлённая версия (2026)

Проект был переработан с целью улучшения структуры и качества кода:

- Улучшена архитектура
- Разделена бизнес-логика и UI
- Уменьшено дублирование
- Повышена читаемость кода
- Пересмотрена ответственность классов

Проект сохранён в репозитории как пример первого опыта разработки и последующего рефакторинга.
